# 花しらべ 計画（2026-11-27）

## 1. 作るもの

スマホでページを開き、「撮る」か「写真を選ぶ」を押すと、花の名前の候補が出るアプリ。

1. 写真を撮る・選ぶ（`<input type="file" accept="image/*" capture="environment">`。アプリのインストールは不要）
2. ブラウザの中で写真を小さく（長い辺 1280px 程度）して JPEG にする
3. 中継に送る → 中継が Pl@ntNet に問い合わせる
4. 候補を上位3つ出す: 和名（参考）・英名・学名・確からしさ（%）
5. ホーム画面に追加できる形（PWA）。uniiqcode.com/hana-shirabe/ で公開（GitHub Pages）

## 2. niisan-tv から使い回すもの・使わないもの

元: `uniiqcode/niisan-tv` の `backend/uniiqcode/identify_flowers.py`、設計は `docs/backend/flower-db.md` §12.4。

| 使い回す | 中身 |
|---|---|
| Pl@ntNet への問い合わせ方 | `POST https://my-api.plantnet.org/v2/identify/all`、`images` に JPEG、`organs=flower`。webp は受け付けないので JPEG にして送る |
| 和名の引き方 | 学名で Wikidata を検索 → 日本語版 Wikipedia へのリンクの題名を和名にする。見つからなければ属の名前（学名の最初の単語）で探し直す。題名の末尾の「属」は削る |
| 失敗から学んだこと | 全文検索だと「キク科」のような大ざっぱな結果になる → Wikidata を使う。User-Agent が無いと Wikimedia に断られる。交雑種（学名に × を含む）は和名が出ないことがある |
| 見た目 | 花ごよみ（`frontend/flower/`）の明朝体（Shippori Mincho）の名前の表示、「Identified by Pl@ntNet」の表記 |

使わないもの: 自宅サーバーのデータベース（MariaDB）、花かどうかの判定（CLIP）、切り抜き（OWL-ViT）、毎晩のまとめ処理（cron）、撮影場所の逆引き。これらは保存済みの写真をまとめて処理するためのもので、その場で1枚調べるこのアプリには要らない。

## 3. 仕組み

```
スマホのブラウザ（GitHub Pages の静的なページ）
   │ 写真（JPEG）
   ▼
中継（Cloudflare Workers）── API キーはここの秘密の値だけ
   │
   ├─▶ Pl@ntNet（学名・英名・確からしさ）
   └─▶ Wikidata（和名）
```

- **キーを隠すために中継が要る。** Pl@ntNet のキーは URL に載る方式で、ブラウザに置く公式の方法が見当たらない。公開ページに書くと誰でも使えてしまい、1日500回の枠をすぐ使い切られる。
- Cloudflare Workers をおすすめする理由: uniiqcode.com の DNS はもう Cloudflare にある、無料枠（1日10万回）で足りる、自宅サーバーが止まっても動く。
- 中継は uniiqcode.com からの呼び出しだけを受け付ける（Origin の確認）。
- 和名は中継で引いてもブラウザで引いてもよい。中継でまとめると、ブラウザの通信が1回で済む。

## 4. Pl@ntNet の条件（2026-11-27 に料金のページで確認）

- 無料: 1日500回まで（UTC 0時＝日本時間 9時に戻る）。超えると 429 が返る → 「今日は上限に達しました」と出す
- 無料枠の中なら商用でも使える。「Powered by Pl@ntNet」の表記は任意（入れる）
- 1人1つの無料アカウント
- **キーは niisan.tv の毎晩の処理とは別に新しく取る**（niisan.tv は毎晩400回まで使っているため、同じキーだと枠が足りない）。同じアカウントでキーを分けられるか、枠がアカウント単位かは、取る時に確かめる（要確認）

## 5. 気をつけること

- 写真は外部（Pl@ntNet）に送る。ページに「写真は名前を調べるために Pl@ntNet に送ります。保存しません」と書く
- 写真の位置情報（EXIF）は、小さくする時に消える（canvas で描き直すため）
- 和名は参考。「〜かもしれません」の書き方にする
- 確からしさが低い時（例: 20% 未満）は「花をもっと大きく撮ってみてください」と出す
